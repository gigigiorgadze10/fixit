# FixIt — Definition of Done

User Story დასრულებულია მხოლოდ მაშინ, როდესაც ყველა შესაბამისი კრიტერიუმი შესრულებულია.

## საერთო კრიტერიუმები

- [ ] ყველა Given/When/Then Acceptance Criteria დაკმაყოფილებულია.
- [ ] შეცდომის/ცარიელი/loading მდგომარეობები დამუშავებულია.
- [ ] კოდი გადის build-ს, lint-სა და type checking-ს.
- [ ] ახალი ბიზნესლოგიკისთვის არსებობს Unit ან Integration ტესტები.
- [ ] API ცვლილება დაფარულია WebApplicationFactory/API ტესტით.
- [ ] როლი და რესურსის მფლობელობა მოწმდება Backend-ზე; 401/403 სცენარები ტესტირებულია.
- [ ] არ არის ცნობილი Critical/High ხარვეზი.
- [ ] კოდი გაიარა Pull Request review ან ინდივიდუალური self-review.
- [ ] API, მონაცემთა მოდელი, migration და შესაბამისი დოკუმენტაცია განახლებულია.
- [ ] CI წარმატებით დასრულდა; ფუნქცია შემოწმებულია სატესტო გარემოში.
- [ ] GitHub Issue აღწერს საბოლოო შედეგს და მხოლოდ ამის შემდეგ გადადის Done-ში.

## Mobile-specific კრიტერიუმები

- [ ] ძირითადი ეკრანი რეალურ Android ან iOS მოწყობილობაზე ან შესაბამის emulator/simulator-ზე შემოწმებულია.
- [ ] Camera/GPS permission-ის უარყოფისას აპი არ იშლება და აჩვენებს ალტერნატივას.
- [ ] ტოკენები ინახება SecureStore-ში; logout-ისას ლოკალური სესია იშლება.
- [ ] 360 dp მინიმალურ ეკრანის სიგანეზე არ არის კრიტიკული UI overflow.
- [ ] Loading/error/offline მდგომარეობები მომხმარებლისთვის გასაგებია.

## Web Dashboard-specific კრიტერიუმები

- [ ] ძირითადი ხედები 1024 CSS px და მეტ სიგანეზე შემოწმებულია.
- [ ] ფორმები იყენებს სერვერულ ვალიდაციასაც; UI-ს დამალვა წვდომის კონტროლად არ ითვლება.
- [ ] Cookie/CSRF და CORS პოლიტიკა შემოწმებულია.

## File Upload-specific კრიტერიუმები

- [ ] ზომა, რეალური image format და ფაილის შიგთავსი მოწმდება.
- [ ] EXIF მეტამონაცემები იშლება შენახვამდე.
- [ ] ფაილი ინახება private Object Storage-ში; საჯარო მუდმივი URL არ ბრუნდება.
- [ ] Storage/DB შეცდომისას orphan file-ის cleanup/compensation გათვალისწინებულია.
