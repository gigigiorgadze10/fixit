### User Story

როგორც **მოქალაქე**, მსურს ახლახან დასრულებულ განაცხადზე ხელახლა გახსნის მოთხოვნა მიზეზის მითითებით, თუ პრობლემა რეალურად არ მოგვარებულა, რათა მუნიციპალიტეტმა განმეორებით გადაამოწმოს შედეგი.

### Acceptance Criteria

**Scenario 1**
- **Given** მოქალაქის საკუთარი Report Resolved სტატუსშია და დასრულებიდან 7 დღე არ გასულა
- **When** მოქალაქე უთითებს მიზეზს და აგზავნის reopen request-ს
- **Then** იქმნება Pending ReopenRequest; Report რჩება Resolved სტატუსში, სანამ Manager არ განიხილავს

**Scenario 2**
- **Given** არსებობს Pending ReopenRequest
- **When** Manager ამტკიცებს მოთხოვნას
- **Then** მოთხოვნა ხდება Approved, Report ბრუნდება Accepted სტატუსში და Manager-ს შეუძლია ახალი Assignment-ის შექმნა

**Scenario 3**
- **Given** არსებობს Pending ReopenRequest
- **When** Manager უარყოფს მოთხოვნას მიზეზის მითითებით
- **Then** მოთხოვნა ხდება Rejected, Report რჩება Resolved სტატუსში და უარყოფის მიზეზი მოქალაქისთვის ხელმისაწვდომია
