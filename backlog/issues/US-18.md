### User Story

როგორც **მოქალაქე ან საველე თანამშრომელი**, მსურს FixIt-ის ინსტალირებადი Android/iOS აპლიკაციის გამოყენება, რათა ჩემი როლის შესაბამისი მუნიციპალური მოქმედებები ტელეფონიდან შევასრულო.

### Acceptance Criteria

**Scenario 1**
- **Given** მხარდაჭერილ Android ან iOS მოწყობილობაზე აპლიკაცია დაყენებულია
- **When** მომხმარებელი პირველად ხსნის აპლიკაციას
- **Then** ჩნდება საწყისი ეკრანი და როლის შესაბამისი ნავიგაციის სტრუქტურა; აპლიკაცია არ ითხოვს არასაჭირო permission-ებს

**Scenario 2**
- **Given** მომხმარებელი წარმატებით არის ავტორიზებული
- **When** აპლიკაცია იღებს მიმდინარე მომხმარებლის პროფილს
- **Then** აჩვენებს მხოლოდ შესაბამის როლზე განკუთვნილ ნავიგაციას; Backend მაინც ამოწმებს ყველა დაცულ მოთხოვნას

**Scenario 3**
- **Given** მობილურ აპს აქვს მოქმედი Bearer session
- **When** აპლიკაცია აგზავნის დაცულ API მოთხოვნას ან ახორციელებს logout-ს
- **Then** წვდომის ტოკენი ინახება SecureStore-ში და იგზავნება Authorization header-ში; logout-ისას ლოკალური ტოკენები იშლება

- **MoSCoW:** Must have
