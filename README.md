## 1. პროექტის აღწერა

ქალაქში დაზიანებული განათების, ორმოს ან გადავსებული ურნის შესახებ მოქალაქეს არ აქვს მარტივი გზა, რომ მუნიციპალიტეტს შეატყობინოს და გაიგოს, მოგვარდა თუ არა პრობლემა. FixIt არის მობილური აპლიკაცია, რომლითაც მოქალაქე აგზავნის განაცხადს ფოტოთი, კატეგორიით და მდებარეობით. მუნიციპალიტეტის დისპეჩერი ვებ-პანელიდან განაცხადს ანიჭებს თანამშრომელს, რომელიც სამუშაოს დასრულებას ფოტოთი ადასტურებს. მოქალაქე ყოველ ეტაპზე ხედავს, რა მდგომარეობაშია მისი განაცხადი.

## 3. MVP

MVP არის ყველა Must have story: **10 story, 39 ქულა** (US-01, 02, 03, 04, 08, 09, 11, 12, 13, 18). ეს არის სრული ციკლი: მოქალაქე რეგისტრირდება და აგზავნის განაცხადს, დისპეჩერი ანიჭებს თანამშრომელს, თანამშრომელი ამთავრებს სამუშაოს ფოტოთი, მოქალაქე კი ხედავს სტატუსს.

MVP-ში არ შედის: უარყოფა და დუბლიკატები (Should), შეფასება (Could), ანონიმური განაცხადი (Won't). სრული სია და Acceptance Criteria: [BACKLOG.md](BACKLOG.md).

## 6. Definition of Done

Story დასრულებულია, როცა:

- ყველა Acceptance Criteria შესრულებულია;
- ტესტები დაწერილია და CI-ში გადის;
